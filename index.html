5. Data Layer

Room Database

AppDatabase with tables: files, vault_files, text_drafts, scanned_pages, selected_images, recycle_bin

DAOs

  • FileDao — CRUD for FileItem entities with indices on path, dateModified, type, isDeleted, isVault, isPinned, sourceFeature
  • VaultDao — Encrypted vault file management
  • DraftDao — Text-to-PDF draft persistence
  • ScannedPageDao — Smart scan page tracking
  • SelectedImageDao — Image selection state

Key Models

  • FileItem — id, name, path, size, dateModified, type (PDF/IMAGE/TEXT/WORD/UNKNOWN), thumbnailUrl, pageCount, isCompressed, sourceFeature, isDeleted, isVault, isPinned
  • VaultFile — id, originalName, encryptedName, size, type, addedDate, originalPath, iv (AES init vector)
  • WatermarkSettings — text, opacity, fontSize, rotation, position (9 options), color, isTiled, logoUri, password
  • ImageCompressSettings — preset (LOW/MEDIUM/HIGH), customSizeKb, maxWidth/Height, format (JPG/PNG/WEBP), quality, removeMetadata, password, biometric, highPerformanceMode
  • FileSortOrder — Sorting options for file lists
  • FileFilter — Type-based file filtering
  • RecycleBinEntity — Soft-deleted files with restoration info

DataStore Preferences

AppSettingsPreferences (16KB) — Persists 30+ settings including dark mode, follow device mode, text color, language, PDF quality, image format, page size, orientation, margins, file prefix, haptic, biometric lock, vault state, enterprise branding, system monitor, screen protection, and more.

10. Security

  • Biometric App Lock — Full-screen lock overlay on cold start, screen off, and user leave. Uses AndroidX Biometric with fallback handling. Smart skip for system picker intents (camera, file picker).
  • Encrypted Vault — AES-256 encryption with per-file IV. PIN-based access with biometric option. Files encrypted on disk, decrypted on-the-fly for viewing.
  • Screen Protection — FLAG_SECURE prevents screenshots when enabled or when auth is pending.
  • PDF Password — Set/remove passwords on PDFs. Password prompt for protected PDFs across all tools.
  • Asset Brand Protection — Prevents metadata tampering on generated documents.

11. Workers & Background Processing

  • PdfActionWorker (63KB) — Massive foreground worker handling: PDF compression, merging, splitting, image-to-PDF, watermark application, signature placement, text-to-PDF generation, PDF-to-JPG conversion, PDF-to-Word conversion. Shows progress notifications with Android 14+ foreground service type dataSync.
  • RecycleBinCleanupWorker (2KB) — Periodic cleanup of expired recycle bin items based on retention settings. Scheduled via WorkManager on app startup.
